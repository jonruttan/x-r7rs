# known-failures.txt -- the specs this bundle is known to fail.
#
# One "UNIT: TEST" per line, matching the runner's own `FAIL:` lines verbatim.
# Blank lines and #-comments are ignored.
#
# BY NAME, NOT BY COUNT, and the difference is the whole point.  A budget of
# "49 failures" is satisfied by fixing one and breaking another, which is the
# exact event a ratchet exists to catch.  Names catch it; a number cannot.
#
# THE LIST MAY ONLY SHRINK.  tests/spec-gate.sh is red when a failure appears
# that is not here, AND when a line here starts passing -- the second is a fix
# nobody wrote down, and leaving it listed would quietly re-authorise the
# failure later.
#
# MEASURED ALONE, and that is not a detail.  Running this suite alongside the
# other bundles inflates it: under that load a batch can hit the runner's
# timeout, and every test after the timeout in that batch is reported failing
# whatever it would have done.  Two isolated runs give this set exactly.  A
# number taken from a six-suite sweep is a number about the machine.
#
# AGAINST x-lang v0.7.0, which pins x-engine-c v0.1.3.  That pairing is what
# lang.xon declares and what CI checks out, so it is what this list describes.
#
# A line here is not a target and not an excuse.  It is debt this bundle is
# known to be carrying, recorded so it cannot grow in silence.
